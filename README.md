# 🏠 SmartLife
*(Work in Progress)*

Build better habits with structure. SmartLife is a desktop productivity 
system that transforms habit tracking into a data-driven experience using 
clean architecture, service-based design, and analytics-driven insights.

## Architecture
- `core/` — business logic and services
- `data/` — database info
- `database/` — SQLite persistence layer
- `ui/` — presentation layer
